# Original preview media

`a-better-brief.webm` is an original silent, captioned 24-second teaching-interface sample created locally by `web/scripts/create-sample-video.mjs`. It contains system-rendered text and simple shapes only. No Apple/Mobbin media, third-party fonts, music, or instructor likeness is used.

`a-better-brief.vtt` and `brief-worksheet.txt` are original sample captions and a practice worksheet. All fictional courses use this one explicitly identified UI sample; it is not presented as their full paid lesson content. No credentials or remote runtime request is required. Browser-native media controls provide playback, seeking, captions, volume and fullscreen. The silent sample does not establish audio-track behavior.
