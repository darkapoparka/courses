# Home photography and artwork sources

The individual Unsplash pages and the [Unsplash License](https://unsplash.com/license) were checked during this implementation. Twelve new photos/renders were downloaded through the image URLs linked by those pages; `strength.webp` is a WebP derivative of the already documented Ivan Pergasi photograph. No Apple/Mobbin artwork or font file is used.
